# Contributing

Thank you for helping improve INJU.

## Product feedback

Use GitHub Issues for reproducible bug reports, feature suggestions and documentation feedback. Please describe the expected behavior, what happened and the relevant INJU product or platform.

## Source contributions

INJU's application source code is maintained in private repositories, so source-code pull requests cannot be accepted here. This repository may accept small corrections to its public documentation at the maintainers' discretion.

## Security reports

Do not open a public issue for a vulnerability or sensitive operational detail. Follow [SECURITY.md](SECURITY.md) instead.
