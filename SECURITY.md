# Security Policy

Security reports are welcome and handled responsibly.

## Reporting a vulnerability

Please contact the INJU team through the official support channels listed at [inju.uz](https://inju.uz).

Include the affected product, a clear description, reproduction steps and the potential impact. Please do not include credentials, personal data or other sensitive information in a public GitHub issue.

We ask that you give the team reasonable time to investigate and address a report before public disclosure.

## Scope

This public repository contains product documentation only. Reports about the INJU applications, platform or production services should still be submitted through the official channel above.
